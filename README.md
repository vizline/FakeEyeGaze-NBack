# FakeEyeGaze-NBack

Trzecia, niezależna wersja procedury eksperymentalnej. Nie korzysta z kamery ani eye-trackingu. Uczestnik wykonuje słuchowe zadanie 0-back lub 2-back i podczas 12-sekundowej ekspozycji może odsłaniać tekst albo obraz przez przytrzymanie myszy.

Wersja testowa przechowuje dane wyłącznie w pamięci bieżącej karty.
