# FakeEyeGaze-NBack

Trzecia, niezależna wersja procedury eksperymentalnej. Nie korzysta z kamery ani eye-trackingu. Uczestnik wykonuje słuchowe zadanie 0-back lub 2-back i podczas 15-sekundowej ekspozycji może odsłaniać tekst, obraz albo statystyki posta przez przytrzymanie myszy. Każda seria n-back rozpoczyna się 2,5 sekundy przed postem i kończy razem z nim; podczas oceny wiarygodności jest cisza. Nagrania liter wykorzystują polski głos w naturalnym tempie.

Wersja testowa przechowuje dane wyłącznie w pamięci bieżącej karty.
